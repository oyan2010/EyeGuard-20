# EyeGuard 20 - 20-20-20 Eye Protection & Screen Break Companion 👁️✨

An Android application built with **Jetpack Compose** designed to protect your eyesight and eliminate digital eye strain using the clinically-proven **20-20-20 Rule**: *every 20 minutes, take 20 seconds to look at something 20 feet away*.

---

## 🌟 Key Features

- **Automatic Break Enforcement**: Background timer automatically counts down your screen session and alerts you when it's time for an eye break.
- **20-20-20 Rule Companion**: Interactive 20-second countdown with visual cues to guide distance focusing and eye relaxation.
- **Screen Dimming / Rest Overlay**: Helps you disengage from continuous display glare with gentle break prompts.
- **Customizable Intervals**: Adjust session times, rest durations, and notifications to match your work habits.
- **Modern Jetpack Compose UI**: Smooth animations, dark mode aesthetic, and accessible typography.

---

## 🛠️ Tech Stack & Requirements

- **Platform**: Android (minSdk: 26, targetSdk: 34+)
- **UI Framework**: Jetpack Compose & Material 3
- **Language**: Kotlin
- **Build System**: Gradle (Kotlin DSL)

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/oyan2010/EyeGuard-20.git
   cd EyeGuard-20
   ```

2. **Open in Android Studio**:
   - Open Android Studio (Hedgehog or newer recommended).
   - Select **Open** and choose the project directory.
   - Let Gradle sync dependencies.

3. **Run**:
   - Launch on any Android physical device or emulator running API 26 or above.
